# SK9822 Rev. 01 page-7 relative spectra

`sk9822-rev01-p7-relative-spd.csv` is a direct digitization of the red,
green, and blue vector curves in
`normand/addressable-led/SK9822/datasheet.pdf`, page 7, “Wavelength
Characteristics”. Its source PDF SHA-256 is
`c9973c201856c27c88f431568a9a308df3f181f755444734eb2f62d908b6b37e`,
matching the repository's LFS pointer. The original source URL is
<https://cdn-shop.adafruit.com/product-files/2237/SK9822%20LED%20Datasheet.pdf>.

Reproduce the CSV from an available PDF payload with:

```
uv run --with pymupdf python tools/digitize_sk9822_spectrum.py SK9822.pdf measured-profiles/spectra/sk9822-rev01-p7-relative-spd.csv
uv run python tools/digitize_sk9822_spectrum.py --integrate measured-profiles/spectra/sk9822-rev01-p7-relative-spd.csv CIE_xyz_1931_2deg.csv
```

The integration helper uses the CIE 2019 CIE 1931 2-degree CMF data table,
<https://doi.org/10.25039/CIE.DS.xvudnb9b>, downloaded from
<https://files.cie.co.at/Publications-datasets/CIE_xyz_1931_2deg.csv>.
That data is CC BY-SA 4.0; verify SHA-256
`fa663e3535a7e0763a745993a1f0a192eb0275ac46ad2d1befd7626841e713c1` before
using it. The CLI enforces both the PDF and CIE SHA-256 values. It integrates
the product of the piecewise-linear SPD and piecewise-linear 1 nm CMFs exactly
on the union of SPD and CMF knots, so nonuniform vector-curve point spacing
does not change the result. The resulting xy values are:

| channel | x | y | sampled graph sensitivity x | sampled graph sensitivity y |
| --- | ---: | ---: | ---: | ---: |
| blue | 0.14044 | 0.03681 | 0.13820–0.14224 | 0.03340–0.04301 |
| green | 0.02447 | 0.57539 | 0.01731–0.03904 | 0.53479–0.60878 |
| red | 0.69302 | 0.30685 | 0.68720–0.69782 | 0.30207–0.31264 |

The sampled sensitivity range evaluates nine combinations of ±1 nm horizontal
registration and ±0.01 relative-emission ordinate shifts before integration.
It is not a continuous bound or confidence interval. The vector paths crossing
the plotted zero baseline are retained and clipped to zero; outside the first
and last retained sample the integration assumes zero. Consequently unshown
spectral tails are an additional, unquantified truncation uncertainty. The
manufacturer gives neither source measurement error
nor bin/lot variation, and this CSV supplies no inter-channel flux or relative
Y. These are datasheet-derived diode chromaticity estimates, not calibrated
measurements and not runtime-admissible profile data.
